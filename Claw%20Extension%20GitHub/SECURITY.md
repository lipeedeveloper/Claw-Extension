# Segurança

Esta é a versão segura para GitHub do Claw.

- Não existem API keys fixas no código.
- As chaves devem ser configuradas localmente pelo usuário na extensão.
- Logs redigem tokens e chaves antes de exibir status.
- O painel mostra apenas índice/cooldown das APIs, não o segredo completo.
- Não publique chaves reais em commits, issues, prints ou README.
