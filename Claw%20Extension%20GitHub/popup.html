Claw - Assistente IA Universal
Versão 45.0

O que é o Claw?

Claw é um assistente IA completo que funciona diretamente no seu navegador. Ele ajuda a estudar, resumir páginas, explicar respostas, organizar tarefas e controlar páginas web com comandos.

Principais Recursos:

  • Chat IA inteligente com múltiplos modelos
  • Assistente de estudo para Kahoot e StopotS
  • Tradução, resumo e explicação de textos
  • Plugins escolares: YouTube, Spotify, Gmail, Docs, Meet, Classroom, Drive, Wikipedia, Khan Academy, Tradutor e Forms
  • Core IA v45 com memória, flashcards, planner, logs e status das APIs
  • Macro Recorder para automações personalizadas
  • Controle de páginas via comandos
  • Modo discreto de interface (Alt+H)

Como Usar:

  • Alt+Space - Abre o chat flutuante
  • Alt+T - Traduz texto selecionado
  • Alt+S - Resume texto selecionado
  • Alt+E - Explica conceito selecionado
  • Alt+H - Modo stealth (oculta overlays)

Comandos do Chat:

"Abrir YouTube"
"Pesquisar X no Google"
"Clicar em BOTÃO"
"Preencher campo com TEXTO"
"Rolar até o fim"
"Capturar página completa"
"Extrair todos os links"

Modelos IA Disponíveis:

  • GPT-OSS 20B (padrão, rápido)
  • Llama 3.3 70B (poderoso)
  • Llama 4 Scout (preview)
  • Qwen3 (multilíngue)
